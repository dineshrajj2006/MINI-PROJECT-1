The NHL Analytics Dashboard is an end-to-end data engineering and analytics project that uses the official NHL public API to collect real-time hockey data such as teams, players, standings, games, and player statistics. Python and the Requests library are used to fetch the API data, while Pandas is used for data cleaning, transformation, and normalization. The cleaned data is stored in a MySQL database using PyMySQL, with seven relational tables connected using primary and foreign keys. SQL is then used to perform data analysis using queries involving JOIN, GROUP BY, HAVING, ORDER BY, aggregations, and subqueries to identify top scorers, team performance, player statistics, and other insights. Finally, Streamlit and streamlit-option-menu are used to create an interactive dashboard with pages such as Home, Standings, Team Info, Player Search, Game Results, Leaderboards, and SQL Query. The project is developed using Jupyter Notebooks for API data collection and database loading, while the Streamlit dashboard is created using an `nhl_analytics.ipynb` file. To run the project, the required Python libraries are installed, MySQL is configured with the project database, the Jupyter notebooks are executed to collect and load the data, and the dashboard is started using the command `nhldashboard.py`.
